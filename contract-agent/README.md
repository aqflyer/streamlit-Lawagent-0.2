# 合同生成与迭代优化系统(0.2版本)

基于 DeepSeek 大模型 + Streamlit 构建的专业合同智能生成、评分与迭代优化工具，采用**三观四步法**与**风险分配三段论**实现合同全流程智能化管理。

## 修复已知问题

### 1、评估时，模型不同结果不同

不能适配deepseek外的其他接口，原因是评估其他模型不能严格返回json格式。

解决方法：添加方法，强制提取json格式数据。

### 2、增加配置文件

增加配置文件，使得代码结构更加清晰。

### 3、部署时apikey硬编码存在安全问题

采用streamlit官方部署时，官方提供的配置文件。




## ✨ 核心功能

- 📝 **智能合同生成**：基于表单信息快速生成标准化、合规化商事合同
- 🏆 **自动质量评分**：按照 100 分制专业标准自动评分并给出优化建议
- 🔁 **无限次迭代优化**：每次优化均基于上一版合同 + 评分建议，持续提升质量
- 📊 **版本历史管理**：自动保存所有迭代版本，支持回溯查看对比
- 🎯 **格式严格规范**：纯文本合同输出，符合正规商事合同排版要求

## 🧾 支持合同类型

- 商事协议：买卖合同、租赁合同、借款合同、合作协议等
- 服务与劳务：服务协议、技术服务合同、承揽合同等
- 知识产权：保密协议 (NDA)、著作权 / 商标 / 专利相关协议
- 建设工程：建设工程合同、装修装饰合同等
- 其他专项协议

## 🚀 快速开始

### 环境准备

运行

```
# 安装所有必需依赖（re、json为Python内置模块，无需安装）
pip install streamlit openai
```

### 运行应用

运行

```
streamlit run /your path/agent.py
```

### 使用步骤

1. 填写合同基本信息（合同类型、甲乙双方、标的、金额等）
2. 点击**生成合同**获取初始版本与评分
3. 点击**迭代优化**实现基于上一版建议的持续优化
4. 在页面底部查看**所有版本历史**

## 🎯 核心技术

- **Streamlit**：轻量化 Web 界面框架
- **OpenAI SDK**：对接大模型接口
- **智能评分体系**：5 大维度、20 + 细分项专业合同评价标准
- **状态管理**：保存合同迭代历史与版本信息

## 📜 输出规范

严格遵循商事合同标准格式：

1. 纯文本格式，无 Markdown 符号
2. 标准条款编号：第 1 条、第 2 条...
3. 变量使用【【变量名】】标记
4. 结尾统一标注：（以下无正文）
5. 结构：标题→双方信息→鉴于→条款→签署区
